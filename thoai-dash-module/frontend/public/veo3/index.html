Auto_veo3

Tạo video hàng loạt từ prompt và ảnh: Text to Video, Image to Video, Start–End, đồng bộ nhân vật.

Tải Auto_veo3 cho Windows
Đang lấy thông tin phiên bản…

Cài đặt trong 3 bước

  1. Tải file .zip, giải nén vào bất kỳ thư mục nào (không cần quyền quản trị, không cần cài Python hay ffmpeg).
  2. Mở Auto_veo3.exe, bấm Đăng nhập bằng Google, trình duyệt sẽ mở để bạn bấm Cho phép thiết bị này.
  3. Dán prompt, bấm BẮT ĐẦU TẠO VIDEO. Tài khoản mới có gói dùng thử; cần thêm thì bấm MUA GÓI CƯỚC và quét mã QR.

Yêu cầu và lưu ý

  • Windows 10 hoặc 11 (64-bit), có kết nối Internet.
  • Nếu Windows hiện cảnh báo "Windows đã bảo vệ PC của bạn": bấm Thông tin thêm → Vẫn chạy.
  • Mỗi gói cho số máy nhất định. Đổi máy: vào quản lý thiết bị để gỡ máy cũ.
  • Nên dùng prompt tiếng Anh. Video có watermark "Veo" của Google.
